# @edgekits/kernel

`@edgekits/kernel` is the core of the EdgeKits SaaS Kit for Cloudflare Workers: tenancy, policy and entitlements, billing events, provider ports, admin contracts, blueprint configuration, and the Astro and Hono middleware that wires them into an app. Its runtime dependencies are `zod` and `drizzle-orm`, with `hono` as a peer dependency, and it has no Cloudflare runtime dependencies beyond types.

The package is consumed through subpaths only: `@edgekits/kernel/tenancy`, `/policy`, `/events`, `/ports`, `/admin`, `/config`, `/astro` and `/hono`. The package root exports nothing. Inside the package, each subpath lives in `src/<name>/` with its public entry at `src/<name>/index.ts` and private code under `src/<name>/internal/`; a file may import its own subpath relatively, but reaches a sibling only as `@edgekits/kernel/<name>`. ESLint enforces this boundary.

`defineSaaS()` from `@edgekits/kernel/config` describes the SaaS in one typed blueprint, `edgekits.config.ts`: name and locales, tenancy, auth, roles, plans, billing, flags, AI, admin and the installed modules. Providers are chosen with tagged factories such as `tenancy.orgs()`, `auth.betterAuth()` and `billing.paddle()`. The input is parsed with a Zod schema that rejects a malformed blueprint, and the return value keeps the plan keys and the billing provider in its type. The kernel's default roles `owner`, `admin` and `member` are merged under the blueprint's own. `validateAgainstProviders(blueprint, capabilities)` is a separate step that checks the billing choices (currency, model, trials, proration) against a provider's capability manifest, such as `paddleCapabilities` from `@edgekits/kernel/ports`, and returns each unsupported choice with its path.

Tenant data lives in tables declared with `tenantTable()` from `@edgekits/kernel/tenancy`. It wraps Drizzle's `sqliteTable`, adds the `org_id` column and its index, and registers the table as tenant-scoped; the caller never declares `org_id`. A registered table is queried only through `ctx.db.repo(table)` on a `TenantContext`, whose `findMany`, `findById`, `insert`, `update` and `delete` add `org_id = ctx.orgId` to every predicate and set it on every insert; no method takes an org id. A `TenantContext` comes from `resolveTenant()`, which re-verifies membership on every call. Tenant tables are exported from `*.tables.ts` files, and the `kernel/tenant-table-access` lint rule allows importing them only from repositories (`src/**/repo.ts`), the tenancy subpath, other `*.tables.ts` files and tests. In development and tests, `tenantGuardLogger({ mode: 'strict' })` makes Drizzle throw on any select, update or delete of a tenant table without an `org_id` predicate.

The request pipeline is plain Hono middleware from `@edgekits/kernel/hono`, used for API routes and pages alike. `tenant()` reads the session through a callback, takes an org named by an API key or trusted caller over the session's active org, calls `resolveTenant()` and sets `c.var.tenant`; no session, no org or a refused membership responds 404, and the org id is never read from a query string or client header. `errors()` is the `app.onError` handler: a `PolicyError` becomes 402 (entitlement) or 403 (forbidden) with the decision in the body, a `TenancyError` 404, anything else 500 with no detail. `noStore()` adds `Cache-Control: no-store` to authenticated responses that set no cache policy of their own, and `sameOrigin()` rejects mutating requests from an origin outside the allowed list, or without an `Origin` but with a cookie. `@edgekits/kernel/astro` copies `c.var.tenant` and `c.var.admin` into Astro locals with `toLocals()`.

`@edgekits/kernel/admin` provides `accessIdentity()`, which verifies the Cloudflare Access JWT in `Cf-Access-Jwt-Assertion` (RS256 against the team JWKS, with `iss`, `aud` and `exp` checked) and sets `c.var.admin`, or uses a configured identity in `mode: 'dev'`.

Every public function declares its return type (the lint rule `@typescript-eslint/explicit-module-boundary-types` enforces it), and `npm run typecheck` ends with `check:dist`, which builds `dist/` and type-checks its declarations from a consumer's side with `skipLibCheck` off.
